Synchronize from a staging table

Stage source-system changes in an ordinary table, then map its columns onto this target. The highest version for each business key wins regardless of row or batch order. Inserts and updates are full after-images: mapped columns are replaced verbatim (NULL overwrites the old value) while unmapped columns and the original primary key are preserved. A delete tombstones the key, so an older update can never bring the row back. Target rows, applied versions and tombstones commit in one transaction.

Changing the selection reloads the page so its columns can be mapped.
